Dashboard not configured yet

Set up Discord OAuth2 from the bot, then restart the dashboard.

  1. In the Discord Developer Portal → your application → OAuth2, add this redirect URI: {{.Content.redirect_uri}}
  2. Create a Client Secret on that page.
  3. Put that secret in the bot's .env as DISCORD_OAUTH_CLIENT_SECRET=YOUR_SECRET, then restart the bot. Direct LAN access works without a public_url — the redirect URI above is derived from the address you open. For a tunnel/domain instead, set dashboard.public_url in config.yml and register https://your.host/callback.
  4. Client ID used (auto-derived): {{.Content.client_id}}
  5. Listening on: {{.Content.listen}} — localhost only by default; set dashboard.listen: 0.0.0.0:8080 in config.yml to accept LAN connections. When bound, the dashboard is reachable at {{.Content.lan_url}}.
